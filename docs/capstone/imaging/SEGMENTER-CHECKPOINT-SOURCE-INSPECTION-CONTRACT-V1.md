## Descriptor and volume policy

Traverse ancestors through no-follow directory descriptors; bind one regular, singly linked
read-only file descriptor. Compare source/root descriptor and path identities with frozen controls
before/after each read. Root must be user-owned and not group/world writable; invented roots must
also be0700. Reject symlink aliases, devices/directories, replacements, mutation and identity drift.
Actual volume observation uses bounded read-only `diskutil info -plist` on the parent directory;
require the pinned APFS filesystem, mount/UUID, and source/root device consistency. Observe before
and after inspection; no remount/unlock/write probe or filesystem repair. Unknown observation fails.

Hash the entire file once for identity. Subsequent bounded ZIP parsing and restricted fake decoding
use the metered virtual-zero descriptor view, with zero source storage reads. Aggregate cap equals
file length plus8MiB metadata/virtual requests, including repeated reads. No mmap, extraction,
materialized actual tensor content, accelerator, model execution or optimizer restoration.

## Tuple and inventory policy

Maintain the exact83-tensor float32 model signature, source CPU/meta storage/view bounds and exact
uniform namespace mapping. Net remains dict/OrderedDict; tensor values are never reported.
Keep all auxiliary storage/alias accounting. Accept plain tuple only under optimizer/scheduler,
including nested bounded tuples, tagged `tuple` in reports. Net version metadata accepts the
previous bounded primitive/dict/list types; tuple there rejects. Count all visited items/depth,
reject active-path cycles, tuple subclasses, arbitrary attributes/types, nonfinite primitives and
unsafe globals. Repeated shared containers may be inventoried under each path; active cycles fail.
