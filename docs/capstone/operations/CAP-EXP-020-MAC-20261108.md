The model's per-voxel softmax scores rank the three classes. Argmax does not
require lesion score>.5: (.32,.31,.37) is a raw lesion winner. The .4 policy
suppresses it; (.05,.05,.90) survives all three candidates. Confident mistakes
can survive, and weak correct predictions can be removed. Softmax score is not
verified disease probability; calibration is a separate question. See the
[original calibration study](https://proceedings.mlr.press/v70/guo17a.html).

The completed producer retained counts, not the required full probability fields.
The counterfactual .371633→.648455 assumed perfect ground-truth FP removal and
cannot determine a deployable threshold. This experiment measures whether
confidence actually separates correct from incorrect raw lesion predictions.

## Outcomes and prospective utility rule

Report positive36 macro Dice/recall/defined precision, small-total-volume5 recall,
pancreas70 Dice, case detection, **per-case reference-component hit identities**,
empty34 alarms, FP volume and FN counts. Preserve complete raw/candidate masks
through exact replay plus hashes. A detected case cannot compensate for a newly
missed different case/component.

Retain the original proposed utility checks: Dice gain≥.02; no lost raw-hit case
or component; no small-case macro-recall decline; overall macro recall and
pancreas Dice each within−.01; empty alarms and FP volume nonincrease. If several
pass, highest Dice then lower threshold. If none passes, retain raw. Report any
Dice increase that fails a guard as such, not a successful fix. No automatic
application setting changes.

Add a descriptive100-bin confidence histogram among raw lesion winners, split
into reference TP and FP. Publish voxel counts, exact TP/FP removed at each fixed
threshold and a quantized ranking AUC (.5 no separation). This is voxel-weighted
association, not patient-independent uncertainty, guaranteed calibration or a
voxel-level confidence interval. It does not rank missed voxels that were not
raw lesion winners and cannot show whether lowering a threshold recovers them.

## Lossless storage within the existing backup cap

Four full uint8 masks would need about7.93GiB per copy. Instead store a four-bit
native code retaining the raw class, which fixed thresholds the lesion survives,
and the exact nonlesion fallback. Codes0/1 are raw background/pancreas; codes2–9
represent four threshold levels×two fallback classes. Pack two voxels per byte.
All four masks reopen bit-for-bit through this representation; preserve SHA256
for each decoded mask and verify every independent backup after writing.

The hard worst-case payload is half the2,128,136,535 native voxels, plus the
698,140,651-byte checkpoint and32MiB metadata reserve: about1.80GB. Admission
checks actual retained-backup usage and both free-space projections. Compression
can reduce this further but is not assumed to make admission pass. Retain the
original checkpoint on both Mac filesystems, all70 replay files and reports.
No full float probability volumes or optimizer updates are produced.
