# Reference Guide: What Is a BSAAI Capstone?

BSAAI capstones must be **enterprise-quality solutions** that you would be proud to feature on your résumé and LinkedIn.

They should:

- Be built empirically through learning by doing.
- Engage real users, stakeholders, or live datasets.
- Gather feedback from users or stakeholders where appropriate.
- Demonstrate professional implementation, presentation, and documentation.
- Show deep proficiency in one or more core disciplines.

## Core Disciplines

### Data Engineering

**Focus:** Designing scalable data infrastructure.

**Core skills include:**

- Data storage
- Data enrichment
- Data warehousing
- Automated data-ingestion pipelines
- Pipeline orchestration
- Data quality and reliability

**Example technologies:**

- Apache Airflow
- Snowflake
- SQL Server

---

### Machine Learning and MLOps

**Focus:** Building and operating end-to-end model workflows.

**Core skills include:**

- Feature selection
- Model training
- Hyperparameter tuning
- Model evaluation
- Model serving
- Containerized deployment
- Reproducible machine-learning workflows

**Example technologies:**

- Python
- PyTorch
- MLflow
- Flask
- FastAPI
- Streamlit
- Node.js

---

### Data Science

**Focus:** Producing data-driven insights and supporting decision-making.

**Core skills include:**

- Empirical data research
- Computational analysis
- Advanced data visualization
- Dashboard development
- Embedding dashboards into web applications
- Communicating analytical findings

**Example technologies:**

- Python
- Jupyter Notebooks
- Tableau

---

### Applied Artificial Intelligence

**Focus:** Building context-aware intelligent applications.

**Core skills include:**

- Agentic programming
- Context engineering
- AI architecture and design
- Retrieval-augmented generation
- Version control
- Technical documentation

**Example technologies:**

- Claude Code
- Gemini
- ChatGPT
- GitHub
- Visual Studio Code
- Markdown

---

### Strategic Technology Leadership

**Focus:** System optimization, governance, and technical direction.

**Core skills include:**

- Product management
- Project management
- Entrepreneurship
- Architectural design
- Systems thinking
- AI ethics
- AI governance
- Strategic decision-making

**Example technologies and frameworks:**

- Jira
- Confluence
- Claude Cowork
- Agile frameworks
